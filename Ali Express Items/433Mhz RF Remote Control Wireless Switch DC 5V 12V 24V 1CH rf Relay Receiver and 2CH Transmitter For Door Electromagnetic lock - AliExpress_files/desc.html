433Mhz RF Remote Control Wireless Switch DC 5V 12V 24V 1CH rf Relay Receiver and 2CH Transmitter For Door Electromagnetic lock


Relay Receiver Board Parameter

  • Working voltage : DC5V/6V/12V/24V/30V

  • Input/Output : 1V~250V

  • Max current : 10A

  • Max load: 300W

  • RF frequency : 433Mhz

  • Pin : COM/NC/NO

  • Receiver size : 30*35mm

  • Working temperature : -30~+80 Celsius

  • Receiving Sensitivity : >97dbm

  • Amount of storage remote controls : 20 pieces

  • Support encoding : 1527 Learning code /2262 fixed code

  • RF Operating mode : ASK superheterodyne wireless reception

  • Receiving range : Open space is more than 50 meters

  • Remote operating mode : Momentary Mode / Toggle Mode / Latched Mode / Delay Mode







Working Modes: 4 modes
Momentary mode,Toggle mode,Latched mode and Time delay mode

Momentary mode: Press and hold A button, will work;Release A button,will stop. 
Toggle mode: Press A button,will work;press A button again,will stop;
Press B button,will work;press B button again,will stop.
Latched mode: Press A button,will work;Press B button again,will stop.
Time delay mode:  Press and hold on button "A" , turn on;  
Release the button, turn off after 5 seconds(or 10/15 seconds )

How to program
Momentary mode: Press learning button once,press A button once,succeed.
Toggle mode: Press learning button twice,press A button once,Press B button,succeed.
Latched mode: Press learning button 3times,press A button once;press the B button once.succeed.
Time delay mode: Press learning button 4/5/6 times,press A button once,succeed.

Reset:
Press the learning button 8 times. The existing data will be deleted succeed.
